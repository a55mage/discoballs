Key Features

  • Scan local folders, subfolders and read existing metadata
  • Search metadata from online providers (MusicBrainz, iTunes, more to come...)
  • Apply tags, cover and rename your track with just one click
  • Rename files with customizable patterns

Project Characteristics

Fast and stable, developed in React and Rust, with Tauri desktop framework.

Open Source

Transparent codebase, open to collaboration and suggestions.

Metadata First

Built to keep tags, covers, and naming consistent.
