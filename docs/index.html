Key Features

  • Scan local folders recursively and read metadata, embedded covers, and technical audio info.
  • Search metadata and artwork online (MusicBrainz + iTunes), then apply result, cover only, or apply-and-save.
  • Edit tags, import/remove cover art, save metadata, and optionally rename files in one action.
  • Built-in Equalizer Studio: editable bands, preamp, wet mix, custom presets, and startup preset selection.
  • Auto EQ by genre with customizable mapping, including a default fallback for tracks without genre.
  • Playlist editor with drag-and-drop reordering, quick play, and fast add from the library.
  • Advanced player queue with history, load-more pagination, shuffle/repeat controls, and queue cleanup.
  • Multiple visualizer modes (scope, bars, alchemy, turntable) plus synchronized lyrics when timestamps are available.
  • Light/Dark mode, custom accent palette, startup screen selection, and optional auto-open of the default folder.
  • Configurable rename templates with live preview and customizable separator/field order.
